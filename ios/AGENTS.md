# iOS

- Use Node 22 e `npm run mobile:doctor` antes de trabalhar no projeto nativo.
- `ios/App/App/public` e `capacitor.config.json` são gerados; não os edite.
- Para TestFlight, use `npm run ios:testflight`; upload exige autorização.
- Valide no Simulator e em aparelho físico quando permissões, push, câmera ou
  chamadas forem alteradas.
