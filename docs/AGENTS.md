# Documentação

- Mantenha apenas procedimentos atuais, decisões duráveis e checklists
  reutilizáveis.
- Não adicione planos de execução, relatórios de sessão, capturas temporárias
  ou auditorias concluídas; o Git preserva esse histórico.
- Atualize [README.md](README.md) ao criar ou remover uma fonte oficial.
- Toda documentação operacional deve usar comandos existentes em `package.json`.
